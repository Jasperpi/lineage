Lineage

An open framework for reading consumer DNA files and family trees, built so that every statement it makes can be traced to a source.

Nothing you load here is uploaded. Parsing and analysis run entirely in this browser tab. The one optional network call, building an ancestry reference panel, sends only public rsID numbers to Ensembl, never your genotypes.

Sources: relationship ranges from the Shared cM Project v4 (Bettinger 2020, via DNA Painter, CC BY 4.0); allele positions and 1000 Genomes frequencies from Ensembl; trait citations verified against PubMed. Sample data is synthetic. Not a medical device and not medical advice.
